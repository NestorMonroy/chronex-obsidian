# Stakeholders

## Project Stakeholders

### Primary

**Nestor** (Project Owner)
- Role: Architecture decision maker, project lead
- Responsibilities: Technical decisions, documentation reviews
- Interests: Code quality, scalability, documentation clarity

### Secondary

**Development Team**
- Role: Implementation of FASE 1-5
- Interests: Clear specifications, good documentation, consistent conventions

### Tertiary

**Obsidian Vault Users**
- Role: End users of QuickAdd system
- Interests: System usability, reliability, ease of use
