# Obsidian Repository Manager - Plugin Structure

## Overview

This project has been transformed into a professional Obsidian Plugin following the [Obsidian Sample Plugin](https://github.com/obsidianmd/obsidian-sample-plugin) standards.

## Plugin Configuration

### manifest.json
- **id**: `chronex-obsidian`
- **name**: Obsidian Repository Manager
- **version**: 1.0.0
- **minAppVersion**: 1.5.0
- **description**: Automated repository, task, project, and pillar management with QuickAdd and Templater integration

### package.json
- **Entry point**: `main.js` (compiled from `src/main.ts`)
- **Type**: CommonJS module
- **Scripts**:
  - `npm run dev` - Development mode with watch
  - `npm run build` - Production build with TypeScript check
  - `npm test` - Run Jest tests with coverage
  - `npm run lint` - ESLint checks

## Build System

### esbuild Configuration
- **Entry point**: `src/main.ts`
- **Output**: `main.js` (CommonJS format)
- **Bundling**: Enabled with tree-shaking
- **External modules**: Obsidian, electron, CodeMirror modules not bundled
- **Minification**: Enabled in production mode
- **Source maps**: Inline in development, disabled in production

### TypeScript Configuration
- **Target**: ES6
- **Module**: ESNext (converted to CJS by esbuild)
- **Strict mode**: Enabled
- **Source maps**: Inline

## Plugin Commands

The plugin registers 5 commands in Obsidian:

1. **Create Repository** (`repo-create-repository`)
   - Create a new repository with auto-generated ID
   - Uses `createRepository.js` script
   - Applies `repository.md` template

2. **Create Task** (`repo-create-task`)
   - Create a new task with priority and due date
   - Uses `createTask.js` script
   - Applies `task.md` template

3. **Create Project** (`repo-create-project`)
   - Create a new project with phases
   - Uses `createProject.js` script
   - Applies `project.md` template

4. **Create Pillar** (`repo-create-pillar`)
   - Create a new pillar (foundational value)
   - Uses `createPillar.js` script
   - Applies `pillar.md` template

5. **Create Fleeting Note** (`repo-create-fleeting-note`)
   - Create a new fleeting note
   - Uses `createFugazNote.js` script
   - Applies `nota-fugaz.md` template

## Settings Tab

The plugin provides a settings tab with:
- **Author Name**: Default author for metadata
- **Templates Folder**: Path to templates (default: `990-UTILIDADES/991-template`)
- **Scripts Folder**: Path to scripts (default: `990-UTILIDADES/992-script`)
- **Enable Notifications**: Show action notifications
- **Enable Auto-Capture**: Auto-capture in current note

## Integration Points

### QuickAdd Integration
- Plugin works seamlessly with QuickAdd plugin
- Scripts are compatible with QuickAdd UserScript format
- Templates use `{{VALUE:*}}` variable substitution

### Templater Integration
- Templates processed by Templater plugin
- Supports `<% %>` JavaScript code blocks
- Supports `<%= %>` expression evaluation
- Dynamic content generation

## Publishing to Obsidian Community

1. **Prepare release**:
   ```bash
   npm run version
   ```

2. **Build for production**:
   ```bash
   npm run build
   ```

3. **Create manifest.json** (already done):
   ```json
   {
     "id": "chronex-obsidian",
     "name": "Obsidian Repository Manager",
     "version": "1.0.0",
     "minAppVersion": "1.5.0"
   }
   ```

4. **Package files**:
   - `main.js`
   - `manifest.json`
   - `styles.css`

5. **Submit** to Obsidian Community Plugins
